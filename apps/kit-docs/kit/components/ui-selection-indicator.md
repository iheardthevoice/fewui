# ui-selection-indicator

## Usage

Registered globally as `<ui-selection-indicator>` by `app.use(UiLib)`. Local import: `import { SelectionIndicator } from 'fewui'`.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `selector` * | `string` |  | Seçili öğe seçicisi (kapsayıcı içinde aranır). |

\* required
